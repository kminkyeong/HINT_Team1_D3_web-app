AI 회의록 작성

완료된 회의를 선택하고 음성을 녹음·업로드하면, AI가 요약과 할 일을 정리하고 담당자에게 자동 배포합니다.

회의록 작성 열기

업무 자동화 흐름

  1. 회의 등록 → 구글 캘린더 초대 + 참석자별 개인 응답 링크 메일
  2. 참석 응답 → 참석/불참/미정과 맡을 사전 할 일 선택 → 캘린더 일정에 자동 반영
  3. 상태 자동 변경 → 예정 → 진행중 → 완료 (완료되면 주최자에게 회의록 작성 요청 메일)
  4. AI 회의록 → 완료된 회의 선택 → 음성 STT → AI 요약 + 할 일 추출
  5. 할 일 배포 → 담당자별 할 일 메일 + 참석자 전원 회의록 메일 + 캘린더에 요약 반영
  6. 지출 등록으로 팀 월 예산을 처음 넘으면 예산 초과 알림 메일이 발송됩니다.

회의 등록 후 받은 관리자 링크를 보관해 주세요. 회의실 목록은 Google Sheets의 Rooms 시트에서, 팀 목록과 월 예산은 팀예산 시트에서 수정할 수 있습니다.
