AI 회의록

완료된 회의 선택 → 음성 녹음 또는 파일 선택 → Gemini 음성 전사 → Gemini 요약·할 일 추출 → 저장하면 할 일이 담당자에게 자동 배포됩니다.

1. 회의 선택

회의 일정 관리에서 상태가 완료된 회의만 표시됩니다.

2. 음성 녹음 / 파일 선택

Apps Script 실행 환경에서는 마이크 녹음이 차단될 수 있습니다. 이 경우 외부 녹음기에서 저장한 음성 파일을 선택하세요.

00:00

최대 5분 녹음 후 자동 종료합니다. 새 녹음을 시작하면 이전 음성이 교체됩니다.

원본 파일 20MB 이하, 재생 시간 5분 이하.

녹음 파일 저장

선택된 음성이 없습니다.

3. AI 요약

요약 버튼을 누르면 음성이 Gemini API(무료 등급)로 전송됩니다. 무료 등급 데이터는 Google 서비스 개선에 쓰일 수 있으니 실습용 녹음을 사용하세요.

먼저 회의를 선택하세요.

4. 회의 후 할 일

AI가 회의 내용에서 뽑은 할 일입니다. 담당자와 기한을 확인·수정하세요. 담당자는 참석자 중에서 고릅니다.

할 일담당자기한

저장하면 ① 회의록 시트 저장 ② 할 일 등록 ③ 담당자별 할 일 메일 ④ 참석자 전원 회의록 메일 ⑤ 캘린더 일정에 요약 반영이 자동으로 진행됩니다.
