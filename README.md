# HINT 부산 모빌리티 AI (9반) 1조 팀 업무 개선 앱

# 통합 업무 관리 웹앱 – 설치 및 테스트 가이드

신입사원 업무 자동화 교육용 프로젝트입니다.
Google Sheets + Apps Script로 **회의 일정 관리 → AI 회의록 → 할 일 배포**, **영수증 OCR → 팀 예산 관리**를 자동화합니다.
AI 기능(영수증 OCR · 음성 받아쓰기 · 요약)은 모두 **Gemini API 무료 키 1개**로 동작합니다.

> 이 README와 `설치안내.txt`, `_backup_*` 폴더는 Apps Script에 넣지 않습니다. 아래 **코드 파일 9개**만 옮기면 됩니다.

## 1. 전체 흐름 한눈에 보기

```
[회의 일정 관리]
 ① 회의 등록 ─▶ ② 캘린더 초대 + 개인 응답 링크 메일 ─▶ ③ 참석 여부·사전 할 일 선택
                                                          │
                                         (캘린더 일정 설명에 자동 반영)
                                                          ▼
 ④ 상태 자동 변경: 예정 ─▶ 진행중 ─▶ 완료  ──▶ 주최자에게 "회의록 작성 요청" 메일
                                                          │
[AI 회의록]                                               ▼
 ⑤ 완료된 회의 선택 ─▶ 음성 녹음/파일 ─▶ Gemini 받아쓰기 ─▶ Gemini 요약 + 할 일 추출
                                                          │
 ⑥ 저장 ─▶ 회의록 시트 · Tasks 시트 ─▶ 담당자별 할 일 메일 · 참석자 회의록 메일 · 캘린더 반영

[팀 예산]
 영수증 사진 ─▶ Gemini OCR ─▶ 날짜·금액·상호 자동 입력 ─▶ 지출 저장 ─▶ 대시보드 / 예산 초과 알림 메일
```

| 파일 | 역할 |
|---|---|
| `Main.gs` | 화면 연결(주소 처리), 초기 설정, 스프레드시트 메뉴, 공통 함수(권한·Gemini 호출) |
| `Meeting.gs` | 회의 등록·캘린더 초대·참석 응답·상태 자동 변경 |
| `Minutes.gs` | AI 회의록(받아쓰기·요약·할 일 추출)·저장·할 일 배포 |
| `Budget.gs` | 영수증 OCR·지출 저장·예산 대시보드·예산 초과 알림 |
| `IndexHome.html` | 홈 화면 |
| `IndexMeeting.html` | 회의 등록 / 참석 응답 / 회의 관리 화면 |
| `IndexMinutes.html` | AI 회의록 화면 |
| `IndexBudget.html` | 팀 예산 및 영수증 화면 |
| `SharedUI.html` | 모든 화면 위쪽의 공통 메뉴와 스타일 |

## 2. 준비물

| 준비물 | 용도 | 비고 |
|---|---|---|
| Google 계정 | Sheets, Apps Script, 캘린더, Gmail | 일반 Gmail 계정 가능 |
| **Gemini API 키** | OCR · 받아쓰기 · 요약 | 무료, 결제 등록 불필요 ([발급 방법](#3-2-gemini-api-키-발급)) |
| 테스트용 이메일 1~2개 | 참석자 역할 (초대·응답·할 일 메일 확인) | 본인 다른 계정이나 동료 계정 |
| 영수증 사진 1~2장 | OCR 테스트 | JPG/PNG/WEBP, 10MB 이하, 글씨가 선명한 것 |
| 회의 녹음 파일 1개 | AI 회의록 테스트 | **5분 이하**, mp3/m4a/wav 등 ([녹음 예시](#4-6-ai-회의록-작성)) |
| 크롬 브라우저 | 웹앱 사용 | 권장 |

> **무료 등급 주의:** Gemini 무료 등급으로 보낸 데이터는 Google 서비스 개선에 쓰일 수 있습니다. 실제 회사 회의 녹음이나 개인정보가 담긴 영수증 대신 **실습용 자료**를 쓰세요.

## 3. 설치 (약 20분)

### 3-1. 스프레드시트와 Apps Script 만들기
1. [Google Sheets](https://sheets.google.com)에서 **새 스프레드시트**를 만들고, 이름을 정합니다. (예: `통합 업무 관리`)
2. 메뉴 **[확장 프로그램] → [Apps Script]** 를 클릭하면 새 탭으로 편집기가 열립니다.
3. 편집기 왼쪽 위 프로젝트 이름(`제목 없는 프로젝트`)을 클릭해 이름을 정합니다.
4. **코드 파일 9개 만들기**
   - 왼쪽 **[파일]** 옆 **[+]** 를 누릅니다.
     - `.gs` 파일 → **[스크립트]** 선택 → 이름에 `Main` 입력 (`.gs`는 자동으로 붙음)
     - `.html` 파일 → **[HTML]** 선택 → 이름에 `IndexHome` 입력 (`.html`은 자동으로 붙음)
   - 기본으로 있는 `Code.gs`는 이름을 `Main`으로 바꿔서 써도 되고, 삭제해도 됩니다.
   - 각 파일에 이 폴더의 같은 이름 파일 내용을 **전부 복사해 붙여넣기** 합니다.

   | 스크립트(.gs) | HTML(.html) |
   |---|---|
   | `Main` `Meeting` `Minutes` `Budget` | `IndexHome` `IndexMeeting` `IndexMinutes` `IndexBudget` `SharedUI` |

   > 파일 이름이 한 글자라도 다르면 화면이 열리지 않습니다. 대소문자까지 정확히 맞추세요.
5. **[저장]** (Ctrl + S)

### 3-2. Gemini API 키 발급
1. [aistudio.google.com](https://aistudio.google.com) 에 Google 계정으로 로그인합니다.
2. 왼쪽 메뉴 **[Get API key]** → **[Create API key]** 를 누르고 키를 **복사**합니다.
3. 결제(Billing) 연결 화면이 나와도 **연결하지 않습니다.** 연결하지 않으면 무료 등급입니다.

> 신입사원마다 **각자 키를 발급**하세요. 무료 사용량 한도가 프로젝트 단위로 적용되어, 한 키를 여럿이 쓰면 금방 한도에 걸립니다.

### 3-3. 프로젝트 설정 (시간대 · 스크립트 속성)
Apps Script 편집기 왼쪽 **⚙ [프로젝트 설정]** 에서:

1. **시간대** → `(GMT+09:00) 서울` 선택
2. 아래로 내려 **[스크립트 속성] → [스크립트 속성 추가]**

   | 속성 | 값 | 필수 |
   |---|---|---|
   | `GEMINI_API_KEY` | 3-2에서 복사한 키 | ✅ |
   | `WEB_APP_URL` | 3-6에서 배포 후 받은 주소 (`…/exec`) | 배포 후 추가 |
   | `GEMINI_MODEL` | **비워 두세요.** 3-4에서 이 키로 쓸 수 있는 무료 모델을 자동으로 찾아 채웁니다 | 자동 |
   | `BUDGET_ALERT_EMAILS` | 예산 초과 알림 받을 이메일 (비우면 본인) | 선택 |
   | `ALLOWED_DOMAIN` / `ALLOWED_EMAILS` | 사용자 제한 (회사 Workspace 계정용) | 선택 · **일반 Gmail이면 비워 두세요** |

3. **[스크립트 속성 저장]**

> API 키는 절대 `.gs` 코드 안에 직접 쓰지 마세요. 스크립트 속성은 이 스크립트의 **편집 권한이 있는 사람이면 볼 수 있으니**, 시트를 다른 사람과 공유할 때는 **보기 권한**으로 공유하세요.

### 3-4. Gemini 연결 확인
1. 편집기 왼쪽 **< > [편집기]** 로 돌아가 `Main.gs` 를 엽니다.
2. 위쪽 함수 선택 상자에서 **`testGeminiApiKey`** 를 고르고 **[▶ 실행]** 을 누릅니다.
3. 처음 실행하면 **권한 승인** 창이 뜹니다. ([3-5의 권한 승인 방법](#권한-승인-방법) 참고)
4. 이 함수는 **이 키로 실제 호출되는 무료 모델을 차례로 시험해 보고**, 처음 성공한 모델을 스크립트 속성 `GEMINI_MODEL`에 자동 저장합니다.
   아래 **실행 로그**처럼 마지막에 `✅ Gemini 연결 정상`이 나오면 성공입니다. (모델 이름은 계정·시기에 따라 다를 수 있습니다)
   ```
   이 키로 보이는 Flash 모델: gemini-3.8-flash, gemini-3.6-flash, ...
     ✗ gemini-3.6-flash : HTTP 429 ...        ← 무료 등급이 없거나 한도 초과 → 다음 후보로
   ✅ 사용 가능: gemini-3.8-flash → 스크립트 속성 GEMINI_MODEL 에 저장했습니다.
   ✅ Gemini 연결 정상 · 모델: gemini-3.8-flash · 응답: 정상
   ```
   > Gemini 모델은 자주 바뀝니다. 나중에 모델 관련 오류가 나면 **`testGeminiApiKey`를 다시 실행**하면 새 모델을 찾아 저장합니다.

### 3-5. 초기 설정 (setup)
1. 함수 선택 상자에서 **`setup`** 을 고르고 **[▶ 실행]** 합니다.
2. 실행 로그에 오류 없이 `실행이 완료되었습니다`가 나오면 성공입니다.
3. 스프레드시트 탭으로 돌아가 **새로고침(F5)** 하면 다음이 보여야 합니다.
   - 시트 탭: `Meetings` `Attendees` `Tasks` `Rooms` `회의록` `팀예산` `지출내역`
   - 상단 메뉴: **🗂 통합 업무 관리**
4. 시트에 기본 데이터를 확인하거나 수정합니다.
   - **Rooms**: `소회의실 A(4명)`, `중회의실 B(8명)`, `대회의실(16명)` — 이름과 정원은 자유롭게 바꿔도 됩니다. `calendarId`는 비워 두세요.
   - **팀예산**: 팀 6개, 각 월 2,000,000원 — 팀을 추가·삭제해도 코드 수정 없이 반영됩니다.
5. Apps Script 왼쪽 **⏰ [트리거]** 에 `updateMeetingStatuses` (10분마다) 가 있는지 확인합니다.

#### 권한 승인 방법
처음 실행할 때 나오는 순서입니다.
1. **[권한 검토]** → 본인 Google 계정 선택
2. **"Google에서 확인하지 않은 앱"** 화면 → 왼쪽 아래 **[고급]** → **[(프로젝트 이름)(으)로 이동(안전하지 않음)]**
3. 권한 목록 확인 후 **[허용]**
   - 스프레드시트, 캘린더, 메일 발송, 외부 서비스 연결(Gemini), 트리거 권한이 요청됩니다. 모두 이 앱 기능에 필요합니다.

### 3-6. 웹앱 배포
1. 편집기 오른쪽 위 **[배포] → [새 배포]**
2. **유형 선택(⚙)** → **[웹 앱]**
3. 설정
   - 설명: `v1` 등 자유롭게
   - **다음 사용자 인증 정보로 실행: `나`**
   - **액세스 권한이 있는 사용자: `Google 계정이 있는 모든 사용자`** (참석자 역할 계정이 응답 링크를 열 수 있어야 합니다)
4. **[배포]** → (권한 승인이 다시 나오면 승인) → **웹 앱 URL 복사** (주소가 `/exec` 로 끝남)
5. **3-3의 스크립트 속성에 `WEB_APP_URL` 로 이 주소를 추가**합니다.
   > 메일 속 링크가 올바른 주소로 나가게 하는 설정입니다. 꼭 넣어 주세요.

> **코드를 고친 뒤에는** 반드시 **[배포] → [배포 관리] → ✏ 수정 → 버전: `새 버전` → [배포]** 를 해야 웹앱에 반영됩니다. (URL은 그대로 유지)

## 4. 기능별 테스트

순서대로 진행하면 전체 자동화 흐름을 한 번에 확인할 수 있습니다.
각 단계의 **✅ 확인할 곳**을 모두 체크하세요.

### 4-1. 홈 화면
1. 브라우저에서 **웹 앱 URL** 을 엽니다.
2. ✅ 위쪽에 공통 메뉴(홈 / 회의 일정 관리 / 팀 예산 및 영수증 / AI 회의록 작성)와 카드 3개가 보이는지 확인합니다.

### 4-2. 회의 등록
1. 메뉴 **[회의 일정 관리]** (또는 스프레드시트 메뉴 **🗂 통합 업무 관리 → ② 새 회의 등록**)
2. 입력 예시

   | 항목 | 예시 |
   |---|---|
   | 회의명 | `11월 주간 기획 회의` |
   | 회의 날짜 | 오늘 |
   | 시작 / 종료 시간 | **지금부터 10분 뒤 / 20분 뒤** (자동 상태 변경까지 확인 가능) |
   | 회의실 | 중회의실 B |
   | 참석자 | `홍길동, 본인이메일@gmail.com`<br>`김테스트, 테스트용이메일@gmail.com` |
   | 안건 | `1. 지난주 실적 공유` |
   | 사전 할 일 | `실적 자료 준비`<br>`회의실 프로젝터 확인` |

3. **[회의 등록]** → 완료 화면에서 **관리자 링크**와 **참석자별 응답 링크**를 확인합니다.

✅ 확인할 곳
- [ ] **Meetings** 시트: 회의 1행, `status` = `예정`
- [ ] **Attendees** 시트: 참석자 2행, `response` = `미응답`
- [ ] **Tasks** 시트: 사전 할 일 2행, `phase` = `사전`
- [ ] **Google 캘린더**: 일정이 생성되고, 설명에 안건·사전 할 일·참석 응답이 적혀 있음
- [ ] **Gmail (참석자)**: `[회의 초대] …` 메일 + 구글 캘린더 초대 메일
- [ ] **Gmail (본인)**: `[회의 관리] … 관리자 링크` 메일

> 같은 회의실·같은 시간으로 회의를 하나 더 등록해 보세요. **"시간이 겹칩니다"** 오류가 나오면 정상입니다.

### 4-3. 참석자 응답
1. 참석자 메일함의 `[회의 초대]` 메일에서 **[참석 여부 · 할 일 선택하기]** 를 클릭합니다.
2. **참석** 을 선택하고, 사전 할 일 중 `실적 자료 준비` 를 체크한 뒤 **[응답 저장]** 을 누릅니다.
3. 다른 참석자 링크로도 열어서 **같은 할 일을 체크**해 봅니다. 이미 맡은 사람이 있어 선택할 수 없으면 정상입니다.

✅ 확인할 곳
- [ ] **Attendees** 시트: `response` = `참석`, `respondedAt` 시간 기록
- [ ] **Tasks** 시트: `실적 자료 준비`의 `assignee`에 이름 기록
- [ ] **Google 캘린더 일정 설명**: `실적 자료 준비 : (이름)`, `(이름) : 참석` 으로 갱신

### 4-4. 회의 관리 (관리자)
1. 등록 완료 화면 또는 `[회의 관리]` 메일의 **관리자 링크**를 엽니다.
2. ✅ 참석 응답 현황(참석/불참/미정/미응답 인원), 사전 할 일 담당자가 보이는지 확인합니다.
3. 각 참석자 옆 **[링크 복사]** 로 응답 링크를 다시 보낼 수 있습니다.

### 4-5. 회의 상태 변경 → 완료
아래 두 방법 중 하나로 확인합니다.

- **바로 확인:** 관리 화면에서 **[완료]** 버튼 → 확인
- **자동 변경 확인:** 종료 시간이 지난 뒤 최대 10분 기다리거나, 스프레드시트 메뉴 **🗂 통합 업무 관리 → 회의 상태 지금 갱신** 실행

✅ 확인할 곳
- [ ] **Meetings** 시트: `status` = `완료` (시작 시간 이후에는 `진행중`)
- [ ] 관리 화면: **"AI 회의록 작성하기 →"** 링크 표시
- [ ] **Gmail (본인)**: `[회의록 작성 요청] …` 메일 (회의당 1번만 발송)
- [ ] 참석자 응답 링크를 다시 열면 **응답 변경 불가** 안내가 나옴

> **[취소]** 테스트는 별도 회의로 하세요. 취소하면 캘린더 일정이 삭제되고 참석자에게 취소 메일이 가며, 되돌릴 수 없습니다.

### 4-6. AI 회의록 작성
**녹음 준비 (예시 대본 · 1~2분)** — 참석자 이름이 대화에 나와야 담당자가 자동으로 지정됩니다.
> "11월 주간 기획 회의 시작하겠습니다. 지난주 매출은 목표 대비 95%였습니다. 다음 달 프로모션은 진행하기로 결정했습니다. 홍길동님이 다음 주 금요일까지 프로모션 기획안을 작성해 주세요. 김테스트님은 이번 주 수요일까지 예산 견적을 받아 주세요. 이상입니다."

휴대폰 녹음 앱으로 녹음해 PC로 옮기면 가장 확실합니다. (웹앱 안의 마이크 녹음은 Apps Script 환경에서 막힐 수 있습니다)

1. `[회의록 작성 요청]` 메일의 버튼 또는 메뉴 **[AI 회의록 작성]** 을 엽니다.
2. **1. 회의 선택**에서 완료된 회의를 고릅니다. ✅ 회의명·일시·회의실·참석자·사전 할 일이 자동 표시됩니다.
3. **2. 음성** → **녹음 파일 선택**으로 파일을 올립니다. (또는 [녹음 시작])
4. **3. AI 요약** → 요약 형식 선택 → **[AI 요약하기]**
   - `1/2 Gemini가 음성을 텍스트로 받아 적고 있습니다` → `2/2 … 요약하고 할 일을 뽑고 있습니다` (보통 수십 초 소요)
5. ✅ 결과 확인
   - 요약 본문과 `[결정 사항]`이 입력란에 표시됨
   - **4. 회의 후 할 일** 표에 `프로모션 기획안 작성 – 홍길동 – (날짜)` 처럼 담당자·기한이 채워짐
   - 내용·담당자·기한을 직접 수정하거나 **[+ 할 일 추가]** / **[삭제]** 할 수 있음
6. **[회의록 저장 및 할 일 배포]** → 확인

✅ 확인할 곳
- [ ] **회의록** 시트: 1행 추가 (회의ID, 참석자, 내용, 할 일)
- [ ] **Tasks** 시트: `phase` = `회의후` 행 추가, 담당자 이메일 자동 기록
- [ ] **Gmail (담당자)**: `[할 일 배정] …` 메일
- [ ] **Gmail (참석자 전원)**: `[회의록] …` 메일
- [ ] **Google 캘린더 일정 설명**: `■ 회의록 요약`, `■ 회의 후 할 일` 추가
- [ ] 같은 회의로 다시 저장하려 하면 **"이미 회의록이 저장된 회의"** 안내

### 4-7. 팀 예산 및 영수증
1. 메뉴 **[팀 예산 및 영수증]** 을 엽니다.
2. ✅ 월 예산 / 사용 금액 / 남은 예산 / 사용률, 팀별 비교가 표시되는지 확인합니다.
3. **지출 등록 팀** 선택 → 영수증 사진을 끌어다 놓거나 클릭해서 선택 → **[영수증 AI 분석하기]**
4. ✅ 결제일 · 결제 금액 · 상호명 · 사용 용도가 자동으로 채워집니다. 틀린 부분은 고친 뒤 **[지출 내역 저장하기]**
5. **예산 초과 알림 테스트:** **팀예산** 시트에서 해당 팀 월 예산을 영수증 금액보다 작게(예: `1000`) 바꾸고 다시 지출을 등록합니다.

✅ 확인할 곳
- [ ] **지출내역** 시트: 1행 추가 (OCR 원문 포함)
- [ ] 대시보드 금액·건수 갱신
- [ ] 예산을 처음 넘을 때 화면에 ⚠ 안내 + **Gmail**: `[예산 초과] …` 메일

### 4-8. 보안 동작 확인 (선택)
- [ ] 응답 링크 주소의 `r=` 뒤 글자를 일부 바꿔서 열기 → "응답 링크가 올바르지 않습니다"
- [ ] 관리자 링크의 `admin=` 뒤 글자를 바꿔서 열기 → "관리자 링크가 올바르지 않습니다"
- [ ] 다른 계정으로 웹앱에 접속해 브라우저 개발자도구 콘솔에서 `google.script.run.resetData()` 실행 → "관리자 전용 기능" 오류 (데이터 삭제 안 됨)

## 7. 참고: 시트 구성과 주소

### 시트
| 시트 | 내용 | 주요 열 |
|---|---|---|
| `Meetings` | 회의 | meetingId, title, date, startTime, endTime, roomId, status(예정/진행중/완료/취소), eventId, adminKey |
| `Attendees` | 참석자 | meetingId, name, email, token(개인 응답 링크), response(미응답/참석/불참/미정) |
| `Tasks` | 할 일 | meetingId, title, assignee, assigneeEmail, dueDate, phase(사전/회의후) |
| `Rooms` | 회의실 | roomId, roomName, capacity, calendarId, location |
| `회의록` | 회의록 | 회의ID, 날짜, 시간, 회의명, 회의실, 참석자, 내용, 할 일, 등록일시 |
| `팀예산` | 팀별 월 예산 | 팀명, 월 예산 |

> 시트의 **열 제목(1행)은 바꾸지 마세요.** 코드가 열 제목으로 데이터를 찾습니다.

### 스프레드시트 메뉴 (🗂 통합 업무 관리)
| 메뉴 | 동작 |
|---|---|
| ① 전체 시트 초기 설정 | `setup` – 모든 시트 생성 + 트리거 설치 |
| ② 새 회의 등록 | 시트 안에서 회의 등록 창 열기 |

| ③ / ④ / ⑤ | 회의 / 예산 / 회의록 시트만 설정 |
| ⚠ 예산·지출 데이터 초기화 | `DELETE` 입력 시 지출내역·팀예산 초기화 (백업 시트 자동 생성) |

### 알아두면 좋은 동작
- 캘린더 일정은 **배포한 사람(스크립트 소유자)의 캘린더**에 만들어지고, 참석자는 초대를 받습니다.
- 참석 응답은 **이 앱의 응답 링크 기준**입니다. 구글 캘린더 초대의 "예/아니요"와는 연동되지 않습니다.
- 회의 상태는 시간이 지나면 **앞으로만** 자동 변경됩니다(예정 → 진행중 → 완료). 취소는 되돌릴 수 없습니다.
- 회의록은 **회의당 1번** 저장합니다. 저장 후 수정은 `회의록` 시트에서 직접 합니다.
- Apps Script는 한 번 실행에 최대 6분까지라서, 받아쓰기와 요약을 두 번에 나눠 처리합니다.
